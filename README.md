# 📄 PDF Tools — Free Online PDF Utilities

Free online PDF tools for merging, splitting, compressing, and converting PDF files. 100% client-side processing — your files never leave your browser.

**GitHub**: https://github.com/lihualih/pdf-tools

---

## 🛠️ Tools Included

| Tool | Description |
|------|-------------|
| **Merge PDF** | Combine multiple PDF files into one |
| **Split PDF** | Extract specific pages from a PDF |
| **Compress PDF** | Reduce PDF file size by removing metadata |
| **PDF to Image** | Convert PDF pages to PNG images |
| **Image to PDF** | Convert JPG/PNG images into a PDF |

## ✨ Features

- ✅ 100% client-side processing (no file upload)
- ✅ Privacy-friendly — files never leave your browser
- ✅ Drag and drop file upload
- ✅ Mobile responsive
- ✅ Dark mode support
- ✅ No signup required
- ✅ Free to use

## ⚡ Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- **pdf-lib** — PDF manipulation (merge, split, create)
- **pdf.js** — PDF rendering (PDF to image conversion)
- All processing via CDN libraries, zero server dependency

## 🚀 How to Use

1. Select the tool you need
2. Upload your PDF files (drag & drop or click)
3. Configure options (page range, quality, etc.)
4. Click the action button
5. Download the result
